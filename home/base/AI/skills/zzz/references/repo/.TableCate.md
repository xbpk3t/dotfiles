# TableCate — 分类、代表选型与评分

## 第一步：分类

帮我对以上这些 repo 进行分类。

## 第二步：选代表

从每个分类中选择最好、最主流、功能最全面的 repo，需要能够覆盖掉该分类其他 repo 的功能。

用 table 列出：分类、代表 repo、同分类内可被替代的 repo。

## 第三步：评分

按 5 分制给这些 repo 打一个综合分（依据：「是否主流」「是否实用」），注意评分尽量均匀。

用 table 列出，按 score desc 排序。若评分 < 4，需要说明为啥不实用。
