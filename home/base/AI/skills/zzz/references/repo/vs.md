## what

**是什么：**

给我画个 table 进行对比。慎重选择对比项，并告诉我为什么你做出这个判断。

直接用 ✅、❌ 逐项对比并标记优劣。

## constraint

### must

1. 维度数量 4–8 个，每个维度说明「为何选这个维」
2. 单元格必须是 ✅ 或 ❌ + 半句事实依据
3. 结论 ≤3 条，若目标是 X 倾向 Y 要给出理由

### must-not

1. 禁止空 ✅/❌（无依据）
2. 禁止无依据的主观形容词堆砌

## workflow

### 对比维度选择

1. 列出维度表：维度 / 为何选这个维 / 不选哪些常见维（可选）
2. 维度数量 4–8 个

### 对比表

1. 行 = 方案，列 = 对比维度
2. 每格 ✅/❌ + 一句事实依据

### 输出 YAML

1. 执行 [table2yml](table2yml.md)，输出相应 YAML codeblock

### 结论

1. 若目标是 X，倾向 Y，因为 …

## output

**format:** md

**template:**

```markdown
| 维度 | 为何选这个维 | 不选哪些常见维（可选） |
|------|--------------|------------------------|
| ... | ... | ... |

| 方案 | 维度1 | 维度2 | ... |
|------|-------|-------|-----|
| 方案A | ✅/❌ + 依据 | ... | ... |

## 结论（≤3 条）
- 若目标是 X，倾向 Y，因为 …
```
