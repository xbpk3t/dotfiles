# vs — 逐项对比

给我画个 table 进行对比。慎重选择对比项，并告诉我为什么你做出这个判断。

直接用 ✅、❌ 逐项对比并标记优劣。

## 输出

### 对比维度选择

| 维度 | 为何选这个维 | 不选哪些常见维（可选） |
|------|--------------|------------------------|
| ... | ... | ... |

- 维度数量 4–8 个
- 每个维度必须说明「为何选这个维」

### 对比表

| 方案 | 维度1 | 维度2 | 维度3 | ... |
|------|-------|-------|-------|-----|
| 方案A | ✅/❌ + 一句事实依据 | ... | ... | ... |
| 方案B | ✅/❌ + 一句事实依据 | ... | ... | ... |

- 行 = 方案，列 = 对比维度
- 每个单元格必须是 `✅` 或 `❌` + 半句事实依据
- 禁止空 ✅/❌，禁止无依据的主观形容词堆砌



### 输出 YAML

执行 pipeline 中的 `table2yml`（[table2yml.md](table2yml.md)），输出相应 YAML codeblock


### 结论（≤3 条）

- 若目标是 X，倾向 Y，因为 …
