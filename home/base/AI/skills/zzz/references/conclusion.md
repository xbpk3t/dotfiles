# conclusion — 结构化总结

按"一问一答"为一组，逐组处理以下三个部分。

先用 YAML 输出 Metadata，然后按顺序处理 QA、归并提炼、总结。

---

## Metadata

```yaml
session: "<session-id>"
```

---

## QA

### Q&A #{n}

**Q**：
保留原问题语义 >=80%；完整语句，勿压缩为关键词。

**A**：
从以下维度提取要点：
1. 核心论点
2. 数据或依据
3. 具体方案
4. 约束条件

**产出/决议**：
- 所做决定/所选方案/所产产物
- **状态**：已解决 / 待定 / 需跟进

每组用 `---` 分隔。
