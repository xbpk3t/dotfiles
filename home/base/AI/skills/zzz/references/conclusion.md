## what

**是什么：**

按"一问一答"为一组，逐组处理 Metadata → QA → 归并提炼 → 总结。

## constraint

### must

1. 必须严格按照上述顺序输出，不可因内容多或话题统一而合并为散文
2. 所有内容必须在 Q&A 块中呈现，不可用话题标题作主结构

### must-not

1. **不得跳过任一部分**，**不得改用自由式专题文章或主题式分类输出**

## workflow

### 话题总结输入处理

**gate:** 输入为话题总结请求（如"总结与 X 相关的讨论"）

1. 先搜索对话历史/笔记/代码中与话题相关的显式问答对 → 逐对映射为一个 Q&A 块
2. 若无显式问答，将材料拆解为隐含问答对
3. 每组 Q&A 均按模板填写，不得合并多个问答为一段叙述
4. Metadata 的 total_qas 按实际提取的 Q&A 对数量填写

## QA

### Q&A #{n}

**Q**：
保留原问题语义 >=80%；完整语句，勿压缩为关键词。

**A**：
从以下维度提取要点。每个维度用 **粗体标签** + 说明展开，必要时使用 `-` 子要点分述：

1. **核心论点**：一句话概括本次回答的核心主张或颠覆性认知
2. **数据/依据**：支撑论点的具体现象、数据、事实
3. **具体方案**：行动路径或分解项
4. **约束条件**：方案/认知的边界、语境限制或未深入的方面

**产出/决议**：
- 所做决定/所选方案/所产产物
- **状态**：已解决 / 待定 / 需跟进

每组用 `---` 分隔。
