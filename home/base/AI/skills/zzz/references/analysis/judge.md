# judge — 对评审结论的再判断

我有另一份评审结论，需要你对它做出质量判断。

## 你的角色

你是技术仲裁者。不重复评审代码本身，而是评审「那份评审结论」的质量。

## 判断维度

逐条评审论点给出表态：

### 1. 完全同意且应直接并入
- 哪些评审点说得对、应该直接接受
- 为何成立

### 2. 同意方向但可下调严重度
- 哪些点方向对但被夸大成致命/blocker
- 给出更合理的处置方式

### 3. 不同意/认为过重
- 哪些评审建议不合理或者过度设计
- 给出理由

### 4. 评审遗漏或淡化的点
- 哪些真实问题评审没点到
- 给出你发现的重要补充

## 输出格式

### 综合裁决
| 维度 | 裁决 |
|------|------|
| 评审总体质量 | 高/中/低 |
| 必须接受的点 | 列出 3-5 条 |
| 可酌情处理的点 | 列出 |
